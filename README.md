# PriceLens

Mobilna web aplikacija za očitavanje cijena kamerom i konverziju u EUR i BAM/KM.

## Deploy na Vercel
1. Upload sadržaja ovog projekta na GitHub repository.
2. U Vercelu: Add New > Project.
3. Import GitHub repository.
4. Framework Preset: Other.
5. Deploy.

Kamera zahtijeva HTTPS i dozvolu korisnika za pristup kameri.
